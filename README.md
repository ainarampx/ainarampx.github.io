# Ainara Martínez Pérez — Portfolio

This package is ready for GitHub Pages.

1. Create the public repository `ainarampx.github.io`.
2. Upload the files in this folder to the repository root.
3. Go to Settings → Pages → Deploy from a branch → `main` → `/root`.
4. The portfolio will be available at `https://ainarampx.github.io/`.

`index.html` is self-contained: its styling, JavaScript and project screenshots are embedded directly, so it does not depend on a CSS/images folder. The CV stays as a separate PDF so the CV button works after publication.
